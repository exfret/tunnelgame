# What is this?

The spec is the collection of markdown files that make up these notes. There are many wiki-style links, like [[README|This]]. To view these properly, I highly recommend downloading the note-taking app [Obsidian](https://obsidian.md/ ) and opening the root folder for the spec (the same as the one that holds the main [[README]]) as a vault. This is especially true as the vast majority of these files are exceedingly short, mainly relying on the wiki link connections to get across the relevant information. Folders are also very much recursively nested. A file with the same name as its parent folder usually has information about what the parent folder's purpose is, and what else is in the folder.
