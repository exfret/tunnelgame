Folders have a file with the same name as the folder; this explains the main idea tied to that folder, and also what's in the folder.

These are the top-level divisions:
- [[Characters]]
- [[Ideas]] includes very preliminary thoughts, where I'm not sure how or where to add them yet
- [[Items]]
- [[Locations]] is a good starting point, especially [[Layer 1]] and the [[Locations/Dome/Orphanage/Orphanage]], as well as [[Locations/Dome/Town/Town|Town]] as these go over the main [[Location|Locations]] that can be explored in the start of the story
- [[Mechanics]] goes over game mechanics
- [[Meta]] discusses these notes, the engine, etc.
- [[Storyline]] has information about the progression of the game, the first parts of the progress, as detailed in the [[Overview]], such as [[Training]], are probably a good starting point for seeing how the story goes
- [[World]] is about different types of things you come across in the world, lore aspects, etc.

As mentioned above, starting with [[Storyline]], and especially [[Training]] in there is good.
