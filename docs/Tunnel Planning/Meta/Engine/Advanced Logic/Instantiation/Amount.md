Any [[Instance]] can be given an amount. This is mainly useful for instances that are supposed to represent items/objects, in which case the [[Amount]] usually represents the count of that item/object in the [[Block]]. This is not the same as having multiple instances with their own [[Instance Variables]] and [[Listener|Listeners]]; it's just a property of a single instance with a little bit of hardcoded support for [[Shop|Shops]] and maybe other mechanics in the future. For a lot of [[Block|Blocks]], their [[Instance|Instances]] will and should have an [[Amount]] that is at most one (it doesn't make sense to have multiple [[Characters/Orphanage/Orphans/George|Georges]] somewhere).
