A creepy basement that can be accessed from the [[Rooms]] by unlocking the door at the end of the hallway there with an [[Orphanage Basement Key]]. There is a door to some maintenance tunnels that has been boarded up. There is a place to store some things. There is also a very creepy music box in the corner, which can be activated with a [[Ducat]], which progresses the sword in a stone storyline.
