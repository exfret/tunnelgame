# Description of this project

These notes, which I call the [[Spec]], are used as a central location to organize the entire project. Read the page linked there for more information about how to use this massive jumble of folders and files.

This project is two-fold: It contains a custom [[Engine]]/interpreter, but also I am working on a massive open-world text adventure game named [[Storyline/Overview/Tunnel|Tunnel]] (with some images/UI elements), for which the [[Engine]] is built.

The central source of discussion about the project is my discord, which can be accessed through this link: https://discord.gg/ebHX7Yek9T

The github for the engine (which you've probably already found) is here: https://github.com/exfret/tunnelgame

If you want to author your own text adventure game using the [[Engine|Engine's]] custom YAML-based language, check out the User Manual here: https://docs.google.com/document/d/1f3taHNkb98GWYWGic_f1u_KZ9t4Lo1-WQnai0Ch2OnQ/edit?usp=sharing

There is also an itch.io page for this project, but there's not much going on there at the moment: https://exfret.itch.io/tunnel
